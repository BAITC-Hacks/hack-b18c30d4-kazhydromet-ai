Правила проекта лежат в [AGENTS.md](AGENTS.md) — **читай его, это единый источник правды** для Claude Code и Codex.
Не дублируй правила здесь: меняешь правила — меняй `AGENTS.md`.

## Codex в этом проекте

Codex обязателен по условиям хакатона, он установлен и его можно вызывать как исполнителя:

```powershell
codex exec -C . -s workspace-write "задача: что изменить, в каких файлах, как проверить"
codex exec -s read-only "вопрос по коду без правок"
```

Делегируй Codex объёмные механические правки и всё, что я прошу сделать «через Codex».
После него смотри `git diff` — за результат отвечаешь ты.

## Автокоммит

Раз в час `scripts/autocommit.ps1` сам коммитит и пушит изменения (у каждого участника на своей машине).
Если увидишь чужие коммиты `auto: ...` — это нормально. Перед своим push всегда делай `git pull --rebase`.
