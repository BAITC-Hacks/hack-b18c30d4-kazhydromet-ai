# ГосФин — AI-помощник по финансовым госуслугам

HackAlem AI 2026 · трек «Госуслуги», подтрек «Финансы» · команда Kazhydromet AI

> **Статус:** до старта хакатона в репозиторий добавлен только технический каркас (FastAPI + OpenAI Agents SDK + дашборд) и синтетические демо-данные. Логика под конкретное задание добавляется 23.09.2026.

**Проблема:** _одна фраза, какую боль решаем и для кого._
**Решение:** AI-агент, который сам проверяет начисления и выплаты, находит спорные случаи и объясняет их простым языком со ссылкой на правило.
**Эффект:** _цифра: визитов в ЦОН, дней ожидания, часов работы специалиста._

## Запуск за 1 минуту

```powershell
uv venv --python 3.12 .venv
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
copy .env.example .env   # впиши OPENAI_API_KEY
.\run.ps1                # http://localhost:8000
```

macOS и Linux:

```bash
uv venv --python 3.12 .venv
uv pip install -r requirements.txt
cp .env.example .env
.venv/bin/python -m uvicorn app.main:app --reload --port 8000
```

Без ключа приложение работает в демо-режиме: показывает реальные цифры из данных, но без ответов LLM.

## Архитектура

```
Браузер (web/index.html)
   │  /api/chat
FastAPI (app/main.py) ──► Агент (OpenAI Agents SDK, app/agent.py)
                               │ function calling
                               ▼
              Инструменты (app/tools.py, app/dataset.py) ──► данные (pandas)
```

| Инструмент агента | Что делает |
|---|---|
| `get_summary` | Сводка: начисления, выплаты, просрочки, суммы в бюджет и из бюджета |
| `find_anomalies` | Записи на проверку: дубли выплат, длинные просрочки, необычные отказы |
| `citizen_profile` | Всё по одному ИИН: начислено, выплачено, просрочено, спорное |
| `search_payments` | Поиск по типу услуги, региону, статусу и сумме |
| `refusal_rates` | Доля отказов по выплатам в разрезе регионов |
| `dataset_info`, `query_data`, `find_outliers` | Работа с **любым** загруженным CSV или Excel |

## Данные

`data/payments.csv` — 998 синтетических начислений и выплат (налоги, пошлины, штрафы, пособия, субсидии)
по 120 гражданам, 16 регионов. Генератор: `scripts/gen_data.py`.
ИИН выдуманные, начинаются с `99` — такой серии не существует, реальных персональных данных нет.
Что специально спрятано в данных для демо — `data/STORIES.md`.

Свои данные можно загрузить прямо на главной: кнопка «Загрузить CSV или Excel», агент сам прочитает колонки.

## Работа в команде

Каждый работает в своей папке: `app/` — бэкенд и агент, `web/` — интерфейс, `data/` и `docs/` — данные и материалы.
Перед каждым `git push` делаем `git pull --rebase`. Кто чем занят — в `docs/STATUS.md`, быстрый обзор: `.\scripts\sync.ps1`.

Ключи только в `.env`. Защита от случайного коммита секретов включается один раз:
`git config core.hooksPath .githooks`
