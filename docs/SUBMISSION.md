## Название

Граф денег — от переводов к перечню проверки

## Описание для формы

Команда Kazhydromet AI. Решение кейса Freedom: рабочее место AML-аналитика,
которое превращает обезличенную транзакционную сеть в объяснимый перечень клиентов
для углублённой проверки.

Из исходных Parquet за июль 2026 строим направленный граф: 2 248 клиентов,
3 119 связей, 4 840 переводов. Каждому клиенту назначаем одну из шести ролей
по открытым правилам с числовыми обоснованиями; выделяем 72 кластера и ранжируем
приоритет проверки. Сохраняем 19 изолированных исходных клиентов, а отсутствие
исходящих у четвёртого колена явно отмечаем как границу выгрузки.

В интерфейсе аналитик прослеживает реальные входящие и исходящие переводы по дням,
изучает повторяющиеся маршруты, формирует свой перечень и видит его охват без
двойного счёта. Следующий кандидат предлагается по приросту ещё не охваченных
операций среди топ-50. Отчёт содержит основания, карточки и перечень недостающих
сведений для запроса. Все роли и аномалии — гипотезы, решение принимает человек.

AI-помощник использует восемь инструментов над данными и показывает вызовы.
Без ключа или при сбое внешнего API работает локальный режим по графу.
Стек: Python, FastAPI, pandas, NetworkX, OpenAI Agents SDK, HTML/CSS/JavaScript,
vis-network. Разработка с Codex и Claude Code; новые зависимости ради интерфейса не требуются.

В README — установка, запуск, пороги, ограничения и масштабирование.
docs/JURY-CHECK.md — маршрут проверки; scripts/check_outputs.py — 21 проверка выгрузок;
scripts/smoke_api.py — проверка HTTP API без ключей с отдельным локальным сервером.

Полная проверка одной командой: `scripts/verify.py`. На Windows и Linux прошли
21 + 24 проверки; три CSV и graph.json совпали побайтно. Реальные JSON-отчёты
и SHA-256 сохранены в docs/VERIFICATION-WINDOWS.json, VERIFICATION-LINUX.json и REPRODUCIBILITY.json.

## Перед нажатием финальной кнопки

1. Убедиться, что последние коммиты отправлены в командный репозиторий.
2. Проверить название, описание и ссылку на репозиторий в форме.
3. Если форма требует демонстрационную ссылку: общего опубликованного адреса пока нет;
   локальный `127.0.0.1` не является ссылкой для жюри. Инструкция допускает отсутствие deployed-версии.
4. После отправки убедиться, что платформа показала сохранённое/отправленное решение.
