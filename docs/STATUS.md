## Договорённости (менять только всей командой)

- **Контракт фронт ↔ бэк:** `POST /api/chat` принимает `{"messages": [{"role", "content"}]}`,
  возвращает `{"reply": str, "trace": [{"tool", "args"}], "mode": "live" | "mock"}`.
  Меняешь формат — сначала пиши сюда, потом меняй код.
- **Кейс:** Freedom, «Граф денег» (AML). План и контракт API — docs/PLAN.md, ТЗ — docs/case/TZ.md.
- **Вау-фича демо:** вводим gid → граф фокусируется на узле, видно, откуда пришли и куда ушли деньги, роль объяснена цифрами; агент отвечает «кто собирает деньги с этих пятерых?»
- **Что НЕ делаем:** хардкод gid, чёрный ящик без правил, выдуманные атрибуты клиентов, авторизация и Docker.
