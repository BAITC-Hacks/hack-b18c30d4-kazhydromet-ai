# PC3: аналитический отчёт

Проверено 23.09.2026 на macOS, исходная версия команды `6825fb2`.

## Изменения
- Добавлена краткая сводка выбранных клиентов: найденные, отсутствующие, приоритет, флаги и обрыв выгрузки.
- Основной текст описывает видимые потоки; полное обоснование, баллы и прежние метрики сохранены в таблице.
- При обрыве четвёртого колена исходящие и получатели «не наблюдаются: обрыв выгрузки»; скорость не оценивается.
- Добавлены флаги аномалий и первые три повторяющиеся цепочки с примерами дат и сумм отдельных операций.
- Совместимость дат не доказывает происхождение средств; порядок внутри дня неизвестен, суммы цепочек не складываются.
- Запросы внутри банка отделены от возможной проверки связей через правоохранительные органы.
- Карточка загружается один раз на уникальный gid; публичные сигнатуры и прежние разделы сохранены.
